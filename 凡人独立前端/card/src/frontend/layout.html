                   世界观指导
                  在正文落笔前，校准万物有灵的世界尺度。
                  
        
                  
          
          
          
        
                  
        
                  
        
                  
          
                  
          
                  
             
            世界观指导（正文前独立裁定）
          
                  
          
                  
            独立发起一次模型请求，在正文提示词发送之前产出世界尺度裁定，拼进正文提示词里一起发送。
            它替代传统世界书：所有世界观设定都放进下方「世界规则」，按需裁定后再注入，不再一股脑塞提示词。
          
                  
          
                  
            
            
          
                  
          
                  
            关闭时跳过世界观指导。未命中规则或指导请求失败时，正文照常生成。
          
                  

          
                  
            
              
                  
                 
                世界观指导 API 详细配置 (点击展开/折叠)
              
                  
                              
            
                  
              
                  
              
              
              
              
              
              
              

              
                  
              
              

              
              

              
                  

              
              
              
                  
                默认上限 60000 字符。
                若你新增规则后总量超过此上限，会按顺序截断并明确列出被截断的规则名（不静默丢弃）。
              
                  

              
                  
                
                
                
              
                  
            
                  
          
                  
          
                  

          
                  
          
                  
             
            世界观指导提示词
          
                  
          
                  
            裁定器读资料、输出指导全靠这段。占位符格式 ${名称}，已对齐凡人卡资料通道。
            直接用就行，要改就在下面框里改，保存即生效。
          
                  
          
                  

          
          
          
                  

          
                  
            
            
            
            
          
                  
          
          
          
                  
          
                  

          
                  
          
                  
             
            世界规则（替代传统世界书）
          
                  
          
                  
            所有世界观设定统一放这里。以后新增的世界书类内容也加进规则包，通过针对性裁定应用。
            蓝灯=时刻参与裁定，绿灯=本轮输入命中关键词才参与。
            右边开关一拨即时生效。
          
                  
          
                  

          
          
                  
            
            
            
            
          
                  
          
          

          
                  
            
                  查看与编辑规则
                  
            
            
            
            
            
                  
          
                  
          
          
                  
          
                  

        
                  
        
                  
          
                  
            
                  
              
              
              
            
                  
            
                  保存运行设置和提示词；规则条目在编辑器内单独保存。
                  
          
                  
      
                  
    
                  

    
                  
      
                  
        
        
                  世界演化设置
                  
        
                  
          
                  
            
                  
              
              
            
                  
            
                  
              开启后，系统将在后台为已退场或不在当前场景的NPC进行独立推演，续写其个人经历。
            
                  
          
                  
          
                  
            
                  
              
              
            
                  
            
                  
              开启后，将为离场NPC分批次发起独立的API请求，用于优化长文本上下文。关闭则将所有离场NPC信息一次性发送。
            
                  
            
                  
              
              
            
                  
          
                  
          
                  
            
                  
              
              
            
                  
            
                  
              设置世界演化的触发频率。例如设为3，则每3轮AI回复后触发一次世界演化。默认为1（每轮都触发）。
            
                  
          
                  
          
                  
            
            
          
                  
          
                  
            
                  
               
              自定义演化追踪字段
            
                  
            
                  
              在此处配置你希望在“世界演化”弹窗中看到哪些自定义属性的变化。
