# 修仙经济基准（原著锚点 + 项目估算）

本条仅用于叙事中的价格感、贫富感、交易尺度与资源压力判断。
用于回答"什么东西大概值多少钱""什么身份通常有多少身家""什么场面算大手笔"。
不要求逐项精算，但整体尺度必须前后一致。原著没有完整统一价目表；以下先使用原著硬锚点，再用项目估算补足未明处。

## 一、货币体系

修仙界通用货币为灵石。
若正文未特别说明，普通交易中提到的"灵石"按下品灵石计价；"价值若干灵石"只是估值，不能把同一个数直接改写成若干中品、上品或极品灵石。

原著称低阶/中阶/高阶/超阶灵石；系统 UI 可对应下品/中品/上品/极品灵石。
低阶灵石是低阶坊市和日常交易的主要单位。
一百块低阶灵石兑换一块中阶灵石是公认兑率，但愿意把中阶换成低阶的人很少。
高阶灵石不能简单按固定比例兑换：天南缺矿时，原著写其灵力量虽约百余块中阶，却用上千块中阶也有价无市；后来碧灵岛矿脉使乱星海供给增加，价格与可得性须随地区、时期和矿脉变化。
极品/超阶灵石不作为日常流通货币。人界一块极品现世便能引来大势力争夺；灵界高阶势力、顶级拍卖和大型阵法虽可涉及多块乃至大量极品，也不能把这些特例当成普通任务和个人经营的默认尺度。

灵石用途：
- 交易货币
- 修炼、恢复法力、斗法补给
- 布阵、传送、炼丹炼器、傀儡和大型禁制的消耗

叙事原则：
- 下品灵石用于日常交易、低阶修士消费、坊市常见买卖
- 中品灵石比下品补充灵力更快；人界普通炼气修士通常难得，筑基修士可得宗门资助，也可用于较正式的交易。写赠予、报酬和随身数量时，须符合人物身份与来源
- 上品灵石在人界缺矿地区属于高价值稀缺资源；有高阶矿脉的地区可以交易，仍应出现在高阶交易、宗门储备、重要阵法或有来历的收获中，不作普通任务报酬
- 极品灵石可辅助突破瓶颈、供特殊大阵使用；人界近乎传说，灵界虽有产出，也主要掌握在高阶修士和大势力手中。高阶修士不会把它当作随手可送的普通灵石
- 写中品以上灵石作为赠礼、任务报酬、交易所得或战利品时，先核对给付者确有来源、承担得起成本，收受者的身份与风险足以匹配，数量与地区、时期的供给相符；普通交情、低阶差事和寻常储物袋不得无由产出高阶灵石。巨额重赏可以成立，但须有重大交易、争夺或战略用途的相称背景
- 不能因报价很高就擅自把单位从下品升级成中品、上品、极品；高品灵石的实际支付条件须另有明确依据

## 二、交易方式与以物易物

低阶坊市可以灵石标价，也可以以物换物。原著太南小会中，符箓可标价灵石，也可换同等价值丹药；摊主也会要求"灵石或等价物品"。

中高阶交易中，纯灵石并不总是最优：
- 珍稀药草、丹方、古方、阵旗、法宝材料、符宝、古宝、灵兽材料等常直接互换
- 拍卖可允许等值物品抵押，由店方鉴价
- 元婴及以上所需物常珍贵异常，普通灵石未必能打动对方
- 高阶灵石、极品灵石、千年灵药、罕见材料常比灵石本身更有议价能力

写法规则：低阶常规交易可直接报灵石；珍稀、高阶、不可再生、传承类物品优先写"交换条件/指定材料/灵药补差"，不要一律写成现银买卖。

## 三、身家尺度（简略）

角色财富应与境界、身份、出身、势力背景相匹配。

原著硬锚点：
- 普通低阶修士身上有十来块低阶灵石已算不错；小散修可能辛苦一年只有两块灵石
- 黄枫谷普通低级弟子一年通过工作约二三十块低阶灵石，实际能攒下的更少
- 药园这类高收入低级职务可从每月二块低阶涨到五块低阶，已算低级弟子中的高收入
- 筑基成功后可单辟洞府、免杂务，并每年免费发放一块中阶灵石，另有材料和灵石资助
- 原著结丹客卿有一年三百灵石另加天雷竹的具体待遇；元婴长老可每年领取数千灵石并接触宗门材料。这些是特定职位待遇，不是所有同境界修士的统一年俸
- 结丹、元婴修士可接触大额交易，但高阶资源需求也同步暴涨，不能把现金富裕写成没有资源压力

项目估算使用时，凡人、炼气、筑基、结丹、元婴的身家表只能作为叙事校准，不是原著硬价。越到高阶，财富越应表现为法宝、材料、丹药、矿脉、洞府、势力权限和人情，而不是纯灵石余额。原著里韩立的数十万灵石与数千块中阶灵石来自长期战利品，不能用来估普通元婴或商人的稳定收入。

修正原则：
- 宗门弟子通常比同境界散修更稳定
- 散修现金流往往更紧，资源更零碎
- 炼丹师、炼器师、商行掌柜、家族核心成员通常更富
- 刚经历大战、逃亡、闭关失败、被追杀、被洗劫者，财富应明显缩水
- 得到秘境机缘、宗门赏赐、长辈扶持者，可短期暴富，但不能无缘无故长期富有

## 四、势力财力与宗门经济

宗门/家族经济不是单纯现金库：
- 宗门财力包含灵石矿、坊市店铺租赁、洞府/地火/传送阵/藏书阁收费、药园、灵兽、矿地、材料库、功法库、弟子劳役和战时征调能力
- 黄枫谷坊市有宗门自营铺面，也出租给修仙家族和散修，并有筑基修士驻守维持秩序
- 低级弟子承担矿地监督、坊市执事、灵禽异兽照看、灵药种植等工作，完成后按月给低阶灵石
- 筑基弟子是宗门重点资源投入对象，每年给中阶灵石和材料，义务是在宗门遭大敌时出手
- 高阶灵石、稀有材料、筑基丹主药、秘境产出可被宗门视为战略储备，不应随意流入低阶市场

势力财力数值若无原文证据，只能作为项目估算。写小家族、中等宗门、大宗门、圣地时，优先写库存结构和资源渠道，而不是只报一个灵石总额。
写矿产、商贸或坊市经营时，分清矿脉与货物归谁、当期产量和成交额、开采护卫与阵法等支出、分成和真正落到个人手中的净收入。原著中一座岛居民所缴灵石甚至不够支付防护阵损耗；低阶矿石做一年买卖，不能无来源地写成数十万中品灵石的个人净利。

## 五、物品价格与品阶

原著低阶成交与报价锚点（低阶灵石）：
- 初级下阶空白符纸一打十二张约一块，不能把每张都写成一块
- 初级下阶成符约一到两块；初级中阶符箓约六到十块，防御符更贵；金刚符约九块
- 初级上阶飞天符约三十块，或换同等价值丹药
- 基础功法《长春功》在太南会标价两块；基础秘籍不能因为归为功法就一律比法器昂贵
- 火云剑一类顶阶法器拍卖底价二百块，可拍到四百出头；底价与成交价须分开

装备估价以实际器类、品质、使用条件、状态和出处为主。顶阶法器仍是法器。符箓的原著分阶和灵石的货币等级各有语义，不能换算成装备容器档。
未给出具体行情时，可按器类、品质、稀缺程度、用途、当地供需和流通限制估价；普通低阶消耗品应体现几块至几十块的尺度，装备、阵盘、材料、基础秘籍不能共用一个单价。

原著高阶价格感：高阶妖丹可值万余灵石，古宝及三千年灵药可涉及十万以上报价，卖方仍可能拒绝现金或认为报价过低。灵界顶级拍卖的数百万乃至上亿标价属于特殊重宝和大势力场景；拍卖底价不是成交价，更不能反推普通修士收入。

## 六、非装备物品与交易条件

- 日常恢复、辟谷等普通丹药与境界突破资源须分开估价；筑基丹由大门派把持，主药须争夺，不是普通坊市随时可买的商品
- 精进法力丹药在升仙大会前可有价无市；能否买到与现金身家不是一回事
- 功法与残篇价格取决于完整度、适用境界、能否正常传授和资源限制，按供需和传授限制估价
- 丹方价值取决于原料是否仍可取得；断绝原料的古方可贬值，对能催熟灵药者则另有价值
- 材料以数量、品质、用途与供需计价，须区分一张、一打、一份、一株等单位
- 千年灵草、符宝、古宝、稀有阵旗、高阶灵石等优先写指定交换条件或以物易物，不用统一倍率定死

## 七、收入、任务报酬与散修压力

原著宗门收入锚点：
- 黄枫谷普通低级弟子通过杂务一年约二三十块低阶灵石
- 高收入低级职务可每月二到五块低阶灵石
- 筑基弟子每年免费发一块中阶灵石，并另有材料和灵石资助
- 宗门低级杂务包括矿地监督、坊市执事、灵禽异兽照看、灵药种植等

宗门正常收入随实际差事或待遇周期累计。炼气弟子按已完成的杂务结算，筑基弟子按本门年度供给另计。长时段按实际履职月份合计；接任、调薪和停职按当期变化分段。入门、领取任务和完成差事是三个不同时间点，已经计过的期间不再重复入账。纯粹入门不预付后续收入。预制与实时游戏都以数值规则设定中的「宗门供给与差事收入」作当前估算基准。

散修收入感：
- 散修常缺钱少物，资源和法器不如修仙家族、宗门弟子
- 散修收入没有全书通用的宗门俸禄折算比例，可能某月暴富、某季赤贫；若无稳定营生，不能按宗门弟子的待遇自动发放现金
- 低阶散修可因势单力孤被家族欺压；许多散修会结伴参加交易会
- 小散修一年攒两块低阶灵石也可出现；不要让普通散修长期拥有稳定高额现金流
- 商行、家族核心、炼丹炼器副业、客卿长老、坊市店铺掌柜可明显更富

任务报酬没有全书通用价目表。黄枫谷低级弟子工作一年约得二三十块低阶灵石；天渊城普通轮值报酬不多，危险特殊任务才可能同时给灵石、丹药、宝物及长期免轮值。高额报酬必须从委托人财力、任务难度、目标价值和具体资源渠道推出，不能只按"任务等级"凭空抬币种或加零。

叙事原则：
- 低风险小事不应轻易出现高额报酬
- 高额悬赏必须伴随高危险、高门槛或高政治价值
- 若某次交易、委托、赏赐明显超过人物平时财力，应在剧情中体现震动感、争抢感或谨慎态度
- 雇佣高阶修士通常不是单次小额现金交易，而是客卿名分、长期待遇、利润分成、珍稀材料、秘术、灵石补偿等组合
- 灵界顶级拍卖、虚天鼎交换和大型阵法可以动用巨额灵石或多块极品；这些属于巨型势力、顶尖修士及特殊工程，不可反推寻常委托也应发数千极品

## 八、日常消费与资源压力

原著消费锚点：
- 黄枫谷内部传送阵一次一块低阶灵石
- 岳麓殿二楼看书一时辰一块低阶灵石；复制一份玉筒十块低阶灵石
- 黄枫谷坊市临时摆摊一日一块低阶灵石，并受坊市保护
- 双瞳鼠租借一日一块低阶灵石
- 借用地火、炼丹房、坊市店铺、客栈、炼器炼符服务都可以收费，但具体价格按地点和资源稀缺度浮动

洞府与阵法消耗须区分：天星圣山某洞府百年租费二千七百灵石，平均每年二十七，这是租用灵地的费用。聚灵阵在原著中属于基础阵法，但没有普通聚灵阵的统一年耗硬价。特殊空间阵法一年耗万余灵石并可借灵脉减耗，不能套到普通闭关聚灵阵。普通阵具按明确的维护费和使用时长估算，斗法充能费不当成每月维护费。

修士世界资源始终稀缺。
灵石不仅是消费品，也是修炼资源、材料购买力、关系运作能力与保命底气。

因此叙事上应长期保留以下现实感：
- 低阶修士常为丹药、法器、疗伤、租洞府、赶路费用发愁
- 筑基修士开始有较稳定的资源调度能力，但依旧会为突破材料与高阶法器肉痛
- 结丹及以上虽更富，但其所需资源价格也同步暴涨
- 富有必须是相对概念：对炼气是巨款，对元婴可能只是零头

## 九、地域、战时与黑市差异

地区和场景会改变供需；以下是叙事估算，具体交易仍以当地已知行情为准：
- 偏远/灵脉稀薄地区：物资可能匮乏，高品级物品可能有价无市，不预设所有商品都更便宜
- 中心城池/大型坊市：选择通常更多，热门资源也可能竞争激烈，不统一加价
- 秘境内部/战乱区域：急需的疗伤、保命和阵具可能有溢价，幅度须由实际供需决定
- 黑市/地下交易：禁忌物品、来路不明之物和信息可能有额外风险价，常规物品也须按交易对象判断
- 黄枫谷坊市因靠近元武国、两国不敌对，能出现越国没有的特殊物品，逐年兴隆
- 天星宗以阵法闻名，其坊市更容易买到阵旗阵盘等禁制类法器
- 大坊市、大商铺、秘店、拍卖会比小摊更容易出现珍品
- 战争、大难、秘境前后，修士会集中出售或交换珍稀物品以增强实力，坊市短期兴旺，疗伤、保命、丹药、符箓、法器需求上升
- 临时交易所、军营交易区、黑市/秘店可出现坊市难寻物，也更容易有来路不明、溢价、抵押或以物易物
- 矿脉发现会改变区域灵石供给；高阶灵石是否容易换到，应随地区和时代变化
- 天星城三十九层洞府曾以两千七百灵石租用百年；这是特定洞府的使用费，不能拿它倒算整座圣山的买卖价格

## 十、可信行情与已完成交易

- 若运行时提供【代码已结算交易】、公认价值锚点、当地行情、快速变卖价或特定交易对象估值，这些数字与库存变化是代码已经裁定的可信事实。
- 公认价值锚点表示通常行情下的共识价值；快速变卖价包含急售与流动性折价；特定人物估值还会受需求、境界适配、百艺、库存与关系影响，三者不要求相同。
- 正文只能自然承接已经完成的交易，不得再次增删同一批物品、重复收付款、擅改成交价或用叙事推翻代码判定。
- 未收到代码报价时，本规则只用于价格尺度校准，不得伪造一笔已经完成的系统交易。

## 十一、叙事校准原则

写价格、报酬、身家时，优先保证以下一致性：
1. 与角色境界一致
2. 与角色身份一致
3. 与当前场景级别一致（偏远小摊、宗门坊市、大商铺、秘店、拍卖会、战时临时交易所）
4. 与事件风险一致
5. 与既有剧情中的贫富状态一致

若拿不准，宁可保守，不轻易夸大财富与报酬。
