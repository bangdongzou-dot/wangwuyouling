# 境界尺度、突破动静与神识范围校准（原著参考）

本条用于正文写作的“尺度刹车”。涉及修为表现、突破、灵压、神识、远距离感应、天地异象时必须执行。核心原则：低境界写内在蜕变和局部影响；大动静必须有高阶来源。

## 一、总纲
- 原著分层：下境界为炼气、筑基、结丹、元婴、化神；中境界为炼虚、合体、大乘；上境界为渡劫，过后飞升仙界。
- 筑基通常意味着修行能力和地位显著上升；炼气多数仍是底层弟子、散修、外门杂役级存在。
- 以下寿元只用于叙事参考，以已保存寿元为准：筑基约二百余年，结丹约四五百年，元婴可过千年寿辰，化神两千余年，炼虚以上以万年计，合体老怪常活数万年。境界提升首先改变寿元、身份、资源门槛和社会地位。
- 人界化神极稀少，且受天地元气和界面限制；炼虚、合体、大乘主要属于灵界/魔界等更高舞台。
- 正文禁止把炼气、筑基写成结丹/元婴/化神的声势。若低境界场景出现惊天动地、远处高阶修士被惊动、灵脉大震、天地变色，必须明确归因于高阶法宝、符宝、阵法、禁制、灵脉、天劫、高阶修士出手、真灵/魔族/仙人级力量。

## 二、灵根、资质、机缘的影响边界
- 无灵根：不能感应灵气，原则上不能修炼法力。
- 伪灵根：四五属性混杂，可感应灵气但修炼极慢，常止步炼气三四层，通常无望筑基。
- 真灵根：二三属性，修炼速度明显优于伪灵根。
- 天灵根：单属性，修炼效率以当前实际修炼速度为准，属于可不借药力突破低阶瓶颈的绝顶资质；炼气入筑基不依赖筑基丹，筑基丹只能作为可选辅助。筑基顶峰入结丹时还可绕过常规结丹瓶颈；这不等于所有后续大境界都无瓶颈。
- 异/变异灵根：雷、冰、风、暗等，速度不逊天灵根；若有匹配功法可形成专项优势，但仍要面对结丹等瓶颈。
- 神秘小瓶、丹药、功法、真灵血脉、大气运、先天体质等，只能提高资源、成功率、恢复力、悟性或某类神通表现；不能让炼气一二层自然产生结丹、元婴级天地异象。
- 低境界持有高阶法宝/符宝/宗门禁制时，动静来自“外物被触发”，正文必须点明来源，避免写成角色自身境界威能。

## 三、突破描写尺度
| 境界/突破 | 正文尺度 |
|---|---|
| 炼气小层 | 体内气感、经脉微热、灵力流转、气息稍稳；最多影响一室、一丈、庭院内灵气，不写风云变色。 |
| 炼气后期/大圆满 | 法力更凝实，可多施低阶法术、御器更稳；仍是低阶，不应让远处长老凭天地异象感应。 |
| 炼气入筑基 | 普通资质可重点写筑基丹；天灵根可不借丹药自行突破，若使用也只能作为可选辅助。共同重点是洗髓伐脉、痛楚、杂质排出、真元液化与气息蜕变；动静以洞府/静室/阵法内为主。 |
| 筑基小层 | 修炼周期拉长，瓶颈开始依赖丹药、机缘、心得；可有筑基威压、分神御器、先天真火，但不是天象级。 |
| 筑基入结丹 | 长期准备、压缩液态真元、丹药/功法/机缘并重；洞府灵气波动、护法阵微震可以写，大范围天地异象需慎用。 |
| 结丹小层 | 法宝温养、真火增强、神识扩大、遁速和斗法质变；突破可被附近同阶或阵法察觉，但不宜动辄震动一州。 |
| 结丹入元婴 | 稀有大关，常牵动宗门命运；可写闭关多年、元婴凝成、法力暴涨、局部天象或高阶修士关注，但应是重大事件。 |
| 元婴小层 | 初中后期差距极大，百年/数百年停滞很正常；中期、后期不只是多一点法力，而是区域级威慑。 |
| 元婴入化神 | 人界近乎传说级关口，需秘术、机缘、天地元气条件；失败常见。成功可引起顶级势力震动，但化神在人界反受限制。 |
| 化神小层/飞升灵界 | 人界化神不能随意全力出手，其实际受限程度要有情境依据；化神后期/大圆满涉及飞升灵界，不写成普通闭关升级。 |
| 化神入炼虚 | 灵界尺度，涉及天地元气、法则雏形、肉身/元婴更深蜕变；可有明显天象，但应发生在高阶洞府、灵地、族群护法环境。 |
| 炼虚入合体 | 大族高阶修士层面，突破失败代价重；动静可覆盖山脉、城池级灵地，但需阵法遮蔽、护法、防敌袭。 |
| 合体入大乘 | 族群战略级事件；需长期准备、重宝、真灵材料、护法和机缘。成功后可改变一族格局，不是个人小场面。 |
| 大乘大天劫 | 真正可以写劫云、雷劫、天地元气暴动、远方高阶感应；同阶也会重视，且有陨落风险。 |
| 大乘飞升劫/渡劫 | 飞升劫可持续多日，毁岛灭山，仙界波动可令界面强者感应参悟。此级别才配“界面级异象”。 |

## 四、神识/感知范围校准
| 境界 | 常规感知写法 |
|---|---|
| 炼气 | 近身、室内、院落级；需主动放开神识或借天眼术、法器、符箓。敛息术、禁制可轻易误导。 |
| 筑基 | 洞府、山头、近距离警戒；可分神御器，但神识仍有限。阵法可压到数尺、数丈。 |
| 结丹 | 可主动扫洞府、山谷、数十里乃至百里一二动静；禁制仍能阻断。法宝级斗法才有明显大声势。 |
| 元婴初期 | 百里级是重要参考线；普通元婴再强也不是随意千里锁定。 |
| 元婴中期 | 神识、遁速、压迫感明显高于初期；可在百里级范围造成强烈威慑，神识化形等手段开始出现。 |
| 元婴后期 | 数百里锁定人物气息才可信；百里外察觉异常可写，但仍会被风沙、禁制、敛息、特殊空间削弱。 |
| 化神 | 感知和天地元气联系更深，但在人界受界面限制，不等于全图透视；残留人界者往往避免全力暴露。 |
| 炼虚/合体 | 灵界高阶，可扫数百里、千里乃至更广区域，但具体取决于环境、战场扰动、法阵、魔气、空间限制。 |
| 大乘 | 正常环境可万里级扫查；特殊炼神术可更夸张。但大型战场、魔气、阴煞、禁制能大幅压缩到数百里甚至十余里。 |
| 渡劫/飞升 | 感知重点不是普通神识范围，而是天劫、法则、仙界波动对同阶/界面强者的牵引。 |

## 五、正文硬约束
- 炼气、筑基突破：写内在蜕变和小范围灵气波动，不写天地惊变。
- 结丹、元婴突破：可以写宗门内高阶察觉、护法阵波动、局部灵气聚集，但必须是长期闭关后的大关口。
- 化神以上：每一次突破都应是势力、界面、寿元、天劫、资源共同参与的大事件。
- 若角色有天灵根、异灵根、先天气运、掌天瓶类机缘、高阶法宝或宗门传承，表现应是修炼更快、资源更足、瓶颈更松、同阶更强、外物可借力；不得直接跨两三个大境界表现境界威能。
- “惊天动地、山崩地裂、方圆万里、远隔千里锁定、天地元气狂涌、远处老祖惊觉”等描写，默认至少需要结丹法宝级、元婴斗法级、化神/炼虚以上神通、大阵、天劫或真灵/仙人级来源。
