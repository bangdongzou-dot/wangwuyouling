# 修士体魄与生存能力尺度

本规则用于校准正文中的身体素质、日常生存、饥寒疲惫、凡俗伤病与饮食描写。
存档中的真实状态、伤势与本轮已发生结果优先。体魄差异用于叙事，不凭境界额外修改血量、法力、物防或脚力。

## 一、总纲

修士境界提升不仅是法力增长，也会同步改造肉身、经脉、五感、耐力、恢复力和生存能力。
除非存在重伤、中毒、法力被封、禁制压制、心魔反噬、特殊功法代价或剧情明确削弱，否则修士不应在普通饥寒、风雨、疲惫、凡俗疾病和低烈度环境压力下表现得像凡人。

境界越高，越不依赖凡俗生活条件：
- 可以更久不进食、不饮水、不睡眠。
- 对寒暑、瘴气、湿冷、疲劳和普通病痛有更强抵抗。
- 伤口愈合、失血承受、体力恢复和痛觉控制远超凡人。
- 凡俗野兽、普通兵刃、跌打损伤、风寒饥饿通常不足以构成核心威胁。

但这不等于修士没有肉身限制。高阶修士仍可能被同阶法术、妖兽、毒蛊、阵法、心魔、灵力枯竭、法宝反噬、天劫、界面压制或长期消耗拖入危险。

## 二、饮食与辟谷尺度

| 境界 | 饮食 / 生存表现 |
|---|---|
| 凡人 / 未入道 | 完全依赖凡俗饮食、睡眠、保暖和医药。生火做饭、赶路疲惫、风寒病痛都合理。 |
| 炼气期 | 已强于凡人，但辟谷仍有时限，低阶炼气也有明显日常需求。辟谷丹主要供这一阶段在闭关、赶路或潜伏时延长不进食时间；野外生存能力仍明显强于凡人。 |
| 筑基期 | 肉身完成一次根本蜕变，已经能够长期自行辟谷。数日数月闭关不食、普通寒暑不侵都合理；吃饭更多是口腹之欲、社交礼节、灵食滋养、伪装身份或照顾凡人同伴。 |
| 结丹 / 金丹期 | 法体稳固，凡俗饮食和普通生活条件基本不再是生存必需。除非刻意体验、隐藏身份、恢复伤势、品尝灵膳或参与人情往来，否则不应频繁写成必须生火做饭、担心挨饿受冻。 |
| 元婴期及以上 | 肉身与元婴 / 神魂体系已远超凡人尺度。普通饥寒、凡俗病痛、长途跋涉和野外环境不应构成压力。若仍出现饮食、沐浴、休息等日常行为，应体现为习惯、仪式、享受、伪装、调养或人际互动，而非生存刚需。 |

## 三、正文硬约束

- 禁止把结丹、元婴修士写成会因普通饥饿、寒冷、雨淋、赶路、凡俗病痛而狼狈求生的人。
- 禁止让高阶修士在没有削弱原因时，为了“活下去”必须生火做饭、找水、避寒、睡觉恢复体力。
- 可以写修士吃饭，但必须给出合理语境：灵膳补益、宴席礼法、凡俗伪装、照顾低阶或凡人同伴、口腹之欲、地方风俗、情绪放松等。
- 可以写修士受伤虚弱，但原因必须匹配境界：同阶斗法、法宝反噬、毒蛊禁制、天劫、灵力枯竭、旧伤复发、特殊环境压制等。
- 筑基及以上已经能够长期自行辟谷；不得只因闭关、赶路、潜伏、露宿或普通饥饿，默认安排其持有、生成或服用辟谷丹。只有已有库存、玩家明确选择、交易与任务需求、凡俗伪装或照顾低阶同伴等具体依据时才可使用。
- 日常细节要体现境界差：低阶修士还会经营干粮、辟谷丹、火折、药粉和符箓；高阶修士更常用清洁术、御寒法诀、护体灵光、储物袋物资或灵舟洞府解决问题。
- 若剧情需要让高阶修士表现得像凡人一样生活，必须写成主动选择或伪装，而不是能力不足。

## 四、叙事建议

写高阶修士的日常生存感时，优先表现从容和余裕：
- 暴雨中衣袍不湿，或只以灵力隔开雨幕。
- 荒山露宿时无需忙乱生火，只随手布下禁制、闭目调息。
- 饮茶、用膳、烹鱼、饮酒可以保留，但重点是情绪、人情、风味、灵材滋养，而不是填饱肚子。
- 低阶角色为柴米水火忙碌时，高阶角色可以旁观、帮忙、入乡随俗或刻意隐藏修为，由此形成境界差和人物关系张力。
