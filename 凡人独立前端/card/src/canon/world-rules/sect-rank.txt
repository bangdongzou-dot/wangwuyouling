# 门派等级与境界对应参考

本条将原著核验锚点与本项目宗门制度设定合并使用。寿元只和真实境界绑定，不和宗门地位绑定；外门、内门、核心、亲传、执事、长老、掌门、太上等是组织身份，不能单独反推寿元或战力。

## 凡人江湖门派 / 俗世势力（如：七玄门、野狼帮、惊蛟会、等）：
- 性质：属于凡人武林或俗世政权，绝大多数成员为无灵根凡人，修炼世俗武功/内功（如真气、剑法、硬功）。
- 境界适用：严禁套用下表中的修仙境界与寿元公式。其“掌门、长老、堂主、弟子”仅为世俗江湖职级，修为均为“凡人”。
- 个体例外：只有正文、存档或原著明确证明某个具体成员有灵根且实际修仙时，才按该个人证据处理；不得由所在组织名称或职级反推。

## 寿元与外貌硬锚点

| 境界 | 寿元尺度 | 外貌年龄规则 |
|----------|----------|------|
| 凡人 | 60-80 常见，百岁以上已属少有长寿 | 外貌基本随实际年龄自然衰老 |
| 炼气期 | 约百年尺度 | 比凡人衰老慢，但低阶修士通常不会把资源花在驻颜上 |
| 筑基期 | 活两百多岁很正常 | 外貌常停在壮年附近，但不是自动返老还童 |
| 结丹期 / 金丹期 | 四五百岁大有指望，结丹后也可写五六百年尺度 | 原著明确结丹不会自动返老还童，只是衰老大幅减缓；驻颜需功法、定颜丹等明确原因 |
| 元婴期 | 可过千岁寿诞 | 可长期保持外貌，但老祖也常以苍老形象示人；仍需区分自然外貌、驻颜、易容、化形 |
| 化神期 | 寿元两千余岁，比元婴多活千余年；真实年龄常见 900-1900 | 可长期保持外貌，仍需区分自然外貌、驻颜、易容、化形 |
| 炼虚期 | 每三千年渡一次大天劫，炼虚后期常见寿元超过万载；真实年龄常见 1800-8000 | 同上 |
| 合体期 | 突破合体常耗数千年，合体老怪常活数万年；真实年龄常见 3000-40000 | 同上 |
| 大乘期 | 原著具名大乘进阶三万至六万年，活了不知多少万年；真实年龄常见 30000-100000 | 同上 |

外貌年龄优先读取人物现有记录。区分自然衰老、驻颜、易容和化形；未记录时保守描述年龄感，成年角色不因寿元长就被写成幼儿。

## 修仙门派等级制度（通用设定，按势力体量微调）

| 身份 / 职能 | 常见境界 | 权限与责任 |
|----------|----------|------|
| 低级弟子 / 外事弟子 / 外门弟子 / 杂役弟子 | 炼气1-7层为主 | 地位低，通常承担最多杂务和固定交付任务，如清扫、灵田、灵矿、坊市执事、照看灵禽异兽、搬运、制符炼药等杂学事务；可领取食宿、基础物资、入门功法和低阶月例。正式修行弟子通常有灵根，世俗杂役与正式弟子分开；外门/外事/杂役弟子都偏底层执役，但不要写成完全同义 |
| 内门弟子 | 炼气8-13层 | 可修更完整的基础功法，领取更好资源，有筑基丹或考核优先权；承担内门任务、较技考核、维护宗门体面 |
| 领事弟子 | 炼气顶层，常为服过筑基丹但未筑基者 | 基础功法多到顶峰，法力较强，可带领统管低级执事弟子 |
| 核心弟子 / 筑基弟子 | 筑基初期~中期 | 宗门中坚，可获进阶传承，可获长老指点、独立洞府/山峰、较高资源；必须响应征召参战、承担高风险任务，危急时守护山门 |
| 亲传弟子 | 筑基后期~结丹初期 | 由结丹后期或元婴长辈亲授，可接触师门专门传承、专属法宝、资源优先供应、旁听高层议事、代师传令；地位可等同执事乃至部分长老。亲传是身份不是职级，结丹后师徒传承、政治立场和衣钵义务仍保留 |
| 执事 / 管事 / 堂主 | 筑基中期~后期 | 管理堂口、分配任务、审批低阶资源，拥有有限执法权；培养考核弟子并向长老汇报。执事应主要是筑基级别，不写成凡人或普通炼气底层 |
| 长老 / 供奉 | 结丹初期~后期 | 参与宗门最高决策，独占灵峰，招收亲传，调动战部与资源；镇守宗门、抵御外敌、研修高阶功法术法、培养继承者 |
| 传功长老/授业长老 | 结丹初期~后期 | 授业与功法传承职位；若明确是筑基弟子的正式师父或授业长老，默认至少结丹；若只是普通传功职务，以正文证据为准 |
| 掌门 / 宗主 | 随势力体量浮动 | 掌门负责全宗管理、代表宗门、外交缔盟和道统传承；黄枫谷掌门钟灵道是筑基后期，所以掌门可以是筑基，不固定为结丹后期~元婴初期；大宗掌门可更高 |
| 太上长老 / 老祖 | 通常元婴期及以上 | 最高战力与宗门底蕴，拥有最高决策否决权；宗门存亡之际可直接接管指挥，平日多闭关潜修，非大劫不出 |

宗门职位决定可接触的资源与授权。功法类别、适用境界和具体传承看实际条目；珍贵传承须有师承、秘境、赐予或其他可信来源。

记名弟子是非正式或较低承认度的师徒名分，不是独立杂役职级；可与外门、外事、内门、散修、家族子弟等身份叠加。若写成宗门内弟子，以该宗门真实入门规则和角色记录为准；不得把记名弟子直接等同为杂役。

## 正式宗门身份与散修边界

散修指当前没有宗门弟子、门人、执事、长老等正式成员身份的修士；正式宗门成员不得同时称为散修。客卿、供奉等非正式成员身份不因此自动排除散修身份，但这种组织关系仍须来自当前存档、已发生正文或可信上下文，不得临场编造。

权限与责任分级逻辑：低级弟子、外事弟子、外门弟子和杂役弟子贡献基础劳力、固定交付与杂学事务；内门为可造之材，核心为中坚战力，亲传为传承核心，执事/管事承担组织运转，长老以上承担镇宗与决策。权限逐级开放，责任逐级加重。记名弟子按师徒名分处理，不作为杂役职级。

## 身份与境界双线逻辑

身份代表宗门中的组织定位，境界代表个人实力。同一境界修士可因资历、贡献、志向不同担任不同身份。修行线是“核心弟子 → 亲传弟子 → 长老”，以突破、传承和高阶战力为主；管理线是“内门弟子 → 执事/堂主 → 长老”，以事务、资源、弟子管理为主。

突破大境界会立即改变真实战力、威慑、风险等级与战略价值；正式任命、席位、称谓和职责可以因核验、议事、派系平衡或本人意愿而滞后。尚未受封、仍挂旧职或暂未进入议事序列，只表示组织手续尚未完成，不得据此把高境界人物判成中低层、普通战力或可轻视对象。

筑基中期修士若专注修行、准备冲击结丹，通常留在核心序列；若修行遇瓶颈或志在事务，可转任执事/堂主。两者不是简单高低，而是路径分化；结丹后通常汇合为长老层。

身份变动常见触发：
| 变动类型 | 触发条件 |
|---|---|
| 外门→内门 | 炼气8层以上 + 内门考核/比武/长老认可 |
| 内门→核心 | 突破筑基 + 长老推荐或重大功绩 |
| 核心→亲传 | 被结丹后期或元婴长辈收徒，师徒双方认可 |
| 普通弟子→执事 | 筑基中期以上 + 管理才能 + 长老任命 |
| 执事→长老 | 突破结丹或宗门明确任命 |
| 长老→掌门 | 前任传位/退位/陨落 + 宗门高层认可；境界随势力体量浮动 |
| 降级/除名 | 严重违反门规、叛门、修为被废、犯下大罪 |
| 破格提拔 | 宗门大战后人才断档、灭门级大功、特殊血脉/体质曝光等 |

晋升永远比降级难：升级通常需要境界、考核、功绩和机缘；降级可能只需一次大错。这种不对称性应形成宗门等级制度的压迫感。

## 特殊身份与修为分离

少主、宗主子嗣、真传苗子、掌门亲眷、持令钦差、贵客或家族嫡系等特殊身份，不按上表直接反推境界。其境界必须以正文、存档、年龄、修炼时间和明确战力证据为准。

特殊身份可带来的合理效果：
- 礼法与称谓抬高，低阶或同阶弟子行礼、避让、禀报、安置静室。
- 资源与权限优先，如令牌通行、库房调用、护道人随行、长辈赐宝、特殊课程旁听。
- 未来潜力被看重，NPC可因其出身、灵根、功法或政治前途而结交、试探、讨好或谨慎对待。

特殊身份不能自动带来的效果：
- 不能仅凭头衔抬高境界、神识范围、斗法判断或讲法资格。
- 不能让更高境界或更资深NPC无证据地向其请教常规修行疑难。
- 不能把礼敬写成修行臣服，把资源权限写成战力压制，把未来潜力写成当前实力。

若低境界特殊身份者确有天灵根、特殊体质、专精功法、法宝共鸣或阵法权限，正文只能把影响限定在相应细分领域；例如“借其水属气机观摩一二”“因令牌开启禁制”“由护道人代为判断风险”，不得扩展为全能导师或全场核心战力。

## 人数金字塔与势力体量

低境界远多于高境界是普遍规律，但单个门派或地域的高阶修士数量差异极大。境界不确定时偏向低境界；涉及大晋、乱星海、天南超级大宗、灵界势力时，不得直接套用黄枫谷这种中小宗门金字塔。

| 场景 / 势力 | 原著核验尺度 | 正文约束 |
|----------|----------|------|
| 黄枫谷（越国） | 炼气上万，筑基数百，结丹寥寥数人，元婴一人 | 可作为中小宗门人数模板 |
| 掩月宗（越国） | 越国七派最强；筑基弟子上千，结丹近十；后续至少有两名元婴修士可推断为强宗高层 | 比黄枫谷高阶弟子更多；结丹人数写“近十”更贴原著，不写死“十余” |
| 越国七派整体 | 越国共有掩月宗、黄枫谷、灵兽山、清虚门、化刀坞、天阙堡、巨剑门；掩月宗最强，灵兽山第二，其余差距不大；整体元婴不过数人 | 其他五派不要无证据强行拉开巨大差距；整个越国高阶储备不及天南大宗 |
| 天南大宗 | 元婴是顶尖战力；超级宗门可有数名甚至十数名元婴，多名元婴支撑大宗地位 | 结丹在大宗中更偏中高层骨干，元婴才是战略底牌 |
| 大晋 | 被称为这一界修士圣地、已知修仙界中心，整体实力远超天南；超级宗门拥有数十名元婴也不奇怪 | 大晋宗门和坊市高阶修士密度可显著高于越国/天南普通地区 |
| 乱星海 | 资源丰富、散修众多；有几十名元婴期散修巨枭并入逆星盟，整体可媲美大晋 | 不要把所有散修都写成炼气底层，高阶散修应有机缘、实力或名声支撑 |

## 同一境界在不同势力中的地位感

| 境界 | 小门派/小国 | 中型宗门 | 超级宗门/大陆级势力 |
|---|---|---|---|
| 炼气 | 普通弟子/主力 | 外门底层 | 杂役级外门劳力，但仍是炼气修士 |
| 筑基 | 核心战力/长老级 | 中层骨干/执事 | 内门普通弟子/低阶执事 |
| 结丹 | 掌门/老祖级 | 长老 | 堂主/高阶执事/中高层骨干 |
| 元婴 | 一方霸主 | 太上长老/镇宗之宝 | 长老层/核心高层 |
| 化神 | 罕见，需有来历 | 极罕见，需有来历 | 宗主/太上/战略底蕴 |

先确认势力级别，再对照境界定位。同一个结丹修士在小门派可称老祖，在超级宗门可能只是中高层；执事/堂主通常仍应是筑基级别，不写成凡人掌权。

## 越国七大门派特色

| 门派 | 实力排名 | 特色 | 写作注意 |
|------|----------|------|----------|
| 掩月宗 | 最强 | 提倡双修，弟子至少一半为女性，容貌要求高；筑基弟子上千、结丹近十 | 可写高阶弟子更多、弟子整体更强；不要无证据写死“结丹十余” |
| 灵兽山 | 第二 | 后文揭示其原是魔道御灵宗分支，和御兽御灵体系关联深 | 可写灵兽/御灵风格，但具体灵宠配置以正文或RAG为准 |
| 黄枫谷 | 其他五派之一 | 门内功法既有正派也有邪派，也有独有传承；整体按中小宗门范例处理 | 筑基数百、结丹寥寥、元婴一人是原著明确范例；不要写成越国垫底定论 |
| 清虚门 / 化刀坞 / 天阙堡 / 巨剑门 | 与黄枫谷等其余门派差距不大 | 原著明确“其他几个门派实力差不多，没有悬殊太厉害” | 若需具体门派特色，优先看正文、RAG或已有设定；无证据时不要强行添加绝对特征 |

## 其他常见身份

| 身份描述 | 对应境界/定位 | 写作注意 |
|----------|----------|------|
| 底层散修 | 炼气初中期 | 修仙界最底层流动人口，朝不保夕，资源紧张 |
| 普通散修 | 炼气后期~筑基 | 有一定自保能力，活跃于坊市与任务体系 |
| 散修高手 | 结丹~元婴 | 极少数，通常有机缘、背景、名声或特殊神通 |
| 坊市摊贩/店伙 | 炼气3-7层 | 坊市底层经营者，境界可低但通常懂修仙交易规则 |
| 坊市掌柜/商行东家 | 筑基初期~中期 | 有实力、资本与人脉；若正文写为凡人掌柜，则个人境界按正文，后台和护卫另算 |
| 大商行幕后东主 | 结丹~元婴 | 商业帝国背后的真正话事人 |
| 家族普通子弟 | 炼气~筑基初期 | 家族中的普通成员 |
| 家族嫡系/核心子弟 | 筑基中期~后期 | 有继承权或重点培养对象 |
| 家族族长 | 筑基后期~结丹 | 小型修仙家族掌权者 |
| 大家族老祖 | 结丹~元婴 | 大型修仙家族的真正底蕴 |
| 仆从/侍女 | 凡人~炼气初期 | 低阶服侍人员 |
| 护卫/随从 | 炼气~筑基 | 贴身保护，境界视雇主身份而定；高阶势力可更高 |
| 凡人百姓 | 无灵根者不能感应灵气，原则上不能修炼法力 | 凡人默认无修为；若有灵根或修仙背景必须有明确证据 |

## 使用规则
1. 正文有明确境界描述时以正文为准
2. 仅凭身份推断时参照上表；但先确认势力体量，再决定同一境界在当地的地位感
3. 不确定时偏向低境界（符合金字塔分布）
4. 年龄寿元须匹配境界；外貌年轻必须区分真实年龄、驻颜丹/驻颜功法、易容、化形或特殊体质
5. 管理职位、师承辈分、资源权限和真实境界是独立维度；不得仅凭掌门、少主、亲传、掌柜、钦差等头衔抬高战力
6. 管理线和修行线并行；核心与执事不是单纯高低，而是路径分化
7. 宗门身份不直接赋予功法、器物或属性加成，须有取得和学习的依据。
