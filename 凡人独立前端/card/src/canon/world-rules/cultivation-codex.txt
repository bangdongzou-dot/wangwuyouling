# 修炼宝典
先核对本人当前境界、已修功法、功法掌握、进度、瓶颈、可用资源、环境和实际投入时间。修炼意图或运行时确认的本轮奖励才可能产生修为变化。赶路、休息、经营、旧剧情与历史结算只作背景。丹药必须是本轮实际使用且用途相符，已消耗的资源不能重复结算。
读取本地给出的最终修炼速度百分比作为效率参考，100% 为标准速度。灵根、功法、装备、词条和状态已计入的部分不再次乘入；没有明示的环境修正不自造。修为进度、境界与实际效果以现行运行协议、存档和结算为准。同一境界进度不随叙事需要回落，跌境或散功须有明确事实；关口未突破时描写停滞和准备，功法熟练提升不能替代境界突破。
心魔、外劫和资源短缺须有已发生的因果依据。普通吐纳按修行性质写反应，重大突破才按境界尺度描写。
仅在收到运行时 B1 修炼结算协议时按其要求给出带角色归属的 <cultivation_card>。被运行时双修流程接管时使用其指定入口，正文停在接管处。同一次修炼按单一执行通道结算。NPC 自身修行按其本人状态与已确认行动推进，其叙事不能更新 B1。

## 功法品阶与修炼速度
功法分黄、玄、地、天、仙、道六阶；每阶分下品、中品、上品、极品。第6列写「阶·品」，如「仙阶·极品」。道阶·极品是常规功法最高品阶。功法品阶和人物境界、修炼上限分别记录，越阶获得功法也不能跳过解锁条件。

同阶按下品 / 中品 / 上品 / 极品排列，修炼速度基准如下：
黄阶：+10% / +20% / +30% / +45%
玄阶：+60% / +80% / +120% / +160%
地阶：+200% / +250% / +360% / +500%
天阶：+650% / +800% / +1100% / +1500%
仙阶：+2000% / +2800% / +4000% / +5600%
道阶：+7500% / +10000% / +14000% / +20000%

所有功法必有修速，其他加成依功法特点。按实际装备、已解锁的境界和第8列结算；最后已解锁的明示修速优先，不与基准叠加。只记了阶时按该阶中品基准，未定品阶按入门+10%。正文读取面板最终修速，不再次乘入功法收益。
