# 常见修仙物品名词定义

本规则用于校准《凡人修仙传》世界观中常见物品名词的用途、适用对象和误用边界。
它不替代物品价格、容器判定或运行时结算，只负责防止正文把丹药、灵物和器具写成万能资源。

## 一、突破与瓶颈类

| 名词 | 定义与用途 | 使用边界 |
|---|---|---|
| 筑基丹 | 普通炼气期修士冲击筑基的关键灵药，能增加突破筑基瓶颈的希望。 | 天灵根属于可不借药力突破低阶瓶颈的绝顶资质，炼气入筑基不依赖筑基丹；筑基丹对其只能是可选辅助、交易物或宗门公共资源，不能写成必需目标。其他炼气修士仍按资质与功法判断需求。已筑基者不应把它当作突破资源，只能写成不合适、浪费或低效的精进法力丹药。它由大门派把持，主药来自禁地争夺，不能随意在低阶坊市买到。 |
| 降尘丹 | 乱星海常见的结丹辅助丹药，对假丹境界、筑基顶峰修士冲击结丹有助益。 | 只适合结丹前的大关口准备，不给已结丹修士当普通增进修为丹。因需妖兽内丹和罕见灵药，通常是任务报酬、势力资源或高风险交易。 |
| 雪灵水 / 天火液 | 修士结丹时可提供帮助的两种辅助灵物，可明显提高结丹希望。 | 用于筑基顶峰冲结丹，不用于炼气筑基、结丹后修炼或普通疗伤；若出现，应体现稀缺、渠道和代价。 |
| 补天丹 | 虚天鼎相关顶级灵丹，可弥补五行灵根不纯，对结丹修士凝练元婴大有益处。 | 不要泛化成普通延寿丹或低阶突破药；元婴老怪争夺它多半来自传言、寿元焦虑或瓶颈期待。 |
| 九曲灵参 | 通灵灵药，天地灵气所化，可化为动物或昆虫活动，对凝结元婴大有用处。 | 极其罕见，不能写成普通药材；捕捉、保存、炼丹都需要特殊手段。 |
| 造化丹 | 由灵烛果炼制的古灵丹，化神期以下一生限服一次，可让修士提前体验下一层境界变化，用于突破瓶颈。 | 灵烛果和成丹都难以保存，必须尽快炼制和服用；修为越低效果越明显，不应写成长期库存常备丹。 |
| 培婴丹 | 上古奇药，可让元婴修士的元婴受益，更容易突破元婴期瓶颈。 | 属于元婴层面的稀有资源，不用于炼气、筑基、结丹阶段。 |

## 二、修炼与日常类

| 名词 | 定义与用途 | 使用边界 |
|---|---|---|
| 黄龙丹 / 金髓丸 | 早期常见的增进功力、洗髓类丹药，对低阶炼气修炼有帮助。 | 对炼气后期、筑基及以上很快失效；不能写成长期支撑高阶修炼的主药。 |
| 炼气散 / 聚灵丹 | 古方丹药，可为筑基期修士提供较强灵气，辅助精进法力。 | 频繁服用可能出现抗药性或失效；不应无限叠加成无代价高速升级。 |
| 辟谷丹 | 主要供炼气期等尚不能长期自行辟谷的低阶修士，在闭关、赶路、潜伏时替代饮食；一粒可额外支撑较长时间不进食。 | 筑基及以上不再把它当生存刚需，也不得仅因闭关、赶路或露宿默认生成、携带或服用；已有库存、玩家明确选择、伪装、交易或照顾低阶同伴时仍可出现。辟谷丹不治伤、不解毒、不突破瓶颈，也不等同增进修为丹药。 |
| 定颜丹 | 驻颜丹药，能让容貌维持在服丹时状态。 | 定颜丹只驻颜，不增进法力、不延长寿元、不返老还童；价值主要来自容貌诱惑和稀少原料。 |

## 三、疗伤、解毒与饲养类

| 名词 | 定义与用途 | 使用边界 |
|---|---|---|
| 清灵散 / 解毒丹 | 解毒类药物，可处理常见剧毒、迷香或部分毒伤。 | 不保证破解所有奇毒、阴毒、蛊毒或高阶妖毒；疑难毒物仍需对症药、功法或高阶修士处理。 |
| 养精丹 | 疗伤补元丹药，可减轻内外伤、止血结疤、保住性命。 | 不是起死回生万能药；重伤、断肢、元神伤、法宝反噬仍需更高阶治疗或长期调养。 |
| 饲灵丸 | 古方灵兽丹药，多数妖兽爱食，长期服用可催进灵兽提升阶级。 | 主要用于灵兽、灵虫培养；对噬金虫这类特殊灵虫效果可能很弱，不能保证无限升阶。 |

## 四、器物与材料常识

| 名词 | 定义与用途 | 使用边界 |
|---|---|---|
| 储物袋 | 收纳物品的空间袋，容量和缩小倍数有限。低阶储物袋通常不能认主。 | 不可放活物；低阶储物袋谁抢到谁可取用，公开显露容易招来杀身之祸。 |
| 玉简 / 玉筒 | 修仙界记录功法、地图、丹方、资料的载体，通常以神念读取或复制。 | 不要写成凡人随手能读懂；重要玉简可能有禁制、传承条件或复制限制。 |
| 符宝 | 结丹期以上修士把法宝部分威能封入符箓形成的消耗品。 | 符宝是消耗品，不等同完整法宝；炼气修士只能发挥一小部分，筑基后可凝炼发挥更多，威能耗尽即报废。 |
| 法器 / 法宝 / 古宝 | 法器主要供炼气、筑基使用；法宝通常为结丹期以上炼制和温养；古宝多为古修遗留，威能和驱使条件各异。 | 低阶角色持有法宝、古宝必须有来源和限制；不得把法宝当作坊市常见低阶货。 |
| 阵旗 / 阵盘 | 便携布阵器具，可布置迷踪、防护、禁制、传送或困敌阵法。 | 阵法效果取决于阵具性质、灵石供能、布阵时间和阵法造诣；不能瞬间万能封天锁地。 |
| 灵石 | 修仙界货币，也是修炼、恢复法力、布阵、传送和施法补给资源，分低阶、中阶、高阶、超阶等。 | 灵石不是单纯金币；高阶灵石和稀有属性灵石有战略价值，不能只按固定比例随意兑换。 |
| 千年灵药 / 妖兽内丹 | 炼制高阶丹药、突破丹药和特殊灵丹的重要材料。 | 千年灵药和高阶内丹常引发争夺、拍卖或以物易物，不应随便作为低阶摊货。 |

## 五、使用边界
- 优先使用原著和本项目已确认的物品；原创物品须符合万物有灵的类型、用途和实际来源。
- 丹药必须匹配境界和用途：突破丹、疗伤丹、解毒丹、驻颜丹、辟谷丹、饲灵丹不能互相替代。
- 珍稀物品出现时必须交代来源、代价、渠道或限制；低阶场景尤其不能把筑基丹、降尘丹、补天丹、九曲灵参、符宝、古宝写成随手可得。
