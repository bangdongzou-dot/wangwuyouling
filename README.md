# 凡人修仙传 · 原著补演

Windows PC 版游戏源码。安装包与更新说明请见仓库的 Releases。

## 从源码构建

进入「凡人独立前端」，运行 `npm ci` 安装依赖，再运行 `npm run dist:win` 生成 Windows x64 安装包。项目采用 Node.js 24 和 Electron 33 完成此次构建。

## 1.1.4 更新方式

本版包含 Windows 启动器修复。已有玩家请先正常退出游戏，再下载 1.1.4 安装包覆盖原安装位置；不要先卸载或删除应用数据。游戏内热更新只替换网页内容，不能替换旧启动器。

本版改善已确认的内存放大路径和读档体验；首页动画卡顿及个别真实玩家变量落库失败仍需更多现场诊断，未宣称全部解决。

## 1.1.5 更新方式

本次仅发布 Windows PC 游戏端。完整更新日志见发布包/版本更新日志/v1.1.5-PC版对外更新日志.md。既有存档和自定义年表不会被内置年表自动覆盖；可通过游戏内更新或正常退出后覆盖安装新版，不要删除应用数据。
