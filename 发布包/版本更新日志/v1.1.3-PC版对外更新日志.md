# v1.1.3 更新日志（PC 版）

## 修复

【修复】覆盖安装后仍可能加载旧版本的问题。自动恢复时会打开实际恢复的版本，版本面板同步显示。此项需下载本页安装包覆盖安装。

**安装方式**　请正常退出游戏，下载本页的 Windows x64 安装包并覆盖安装到原位置，原存档和设置可继续使用。游戏内「检查更新」替换的是游戏网页，启动器修复通过本安装包生效。

【修复】向量接口测试成功后，正式回合仍可能提示「URL/Key 缺失」，现在正式检索直接使用「接口与模型 → 功能分配 → 向量化（Embedding 模型）」中分配的接口，无需再填旧向量表单。

更新后，如果已经分配了向量化接口，开启「向量自动注入」并发送一轮新剧情，即可在新楼层的「向量引用」查看结果。旧楼层会保留当时的提示。

【修复】开局落在某个原著事件中间时，已经过时且没有变异的预制节点会自动入账，进度指针会标明哪些已完成、哪些待发生。

【修复】旧人物档案缺少血量或法力时，预制补演会先用可信快照补齐缺项，再保存人物和账本，已有的有效数值照常保留。
